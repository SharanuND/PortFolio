## ⚙️ How to Run Locally

This portfolio is built using standard front-end technologies and does not require a build system.

1. Clone the repository:

   ```bash
   git clone https://github.com/SharanuND/portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio
   ```

3. Open `index.html` in your browser.

   Alternatively, open the project in Visual Studio Code and use the Live Server extension.

> Replace `portfolio` in the commands with your actual repository name if it is different.
